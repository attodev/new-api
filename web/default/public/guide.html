AlRouter를 CLI에서 연결하는 방법

영상으로 빠르게 보거나, 아래 단계별 설명을 따라 직접 연결해 보세요.

환경변수를 직접 등록하거나, CC Switch로 한 번에 등록할 수 있습니다.

영상이 잘 안 보이시나요? 아래 글로도 따라 하실 수 있습니다

단계별로 따라 하기

1

API 키 발급

대시보드 'API 키' 메뉴로 이동해 새로운 API 키를 생성하고, 생성된 키를 복사합니다. 이 키 하나로 이후 모든 설정에 사용합니다.

2

환경변수 등록

터미널에서 셸 설정 파일을 열고 base URL과 API 키를 추가한 뒤, 설정을 적용합니다. 사용하는 CLI의 포맷에 맞는 값을 넣으면 됩니다.

주의아래 예시의 키 값 대신, 실제로 발급받은 키 값을 입력해 주세요.
Anthropic
~/.zshrc
export ANTHROPIC_BASE_URL="https://alrouter.ai"
export ANTHROPIC_API_KEY="sk-발급받은키"
OpenAI
~/.zshrc
export OPENAI_BASE_URL="https://alrouter.ai/v1"
export OPENAI_API_KEY="sk-발급받은키"
Gemini
~/.zshrc
export GOOGLE_GEMINI_BASE_URL="https://alrouter.ai/v1beta"
export GEMINI_API_KEY="sk-발급받은키"
$ source ~/.zshrc
3

연결 확인

새 터미널에서 claude를 실행한 뒤, /status로 AlRouter 연결을 확인합니다. base URL 항목에 alrouter.ai가 표시되면 정상입니다.

주의환경변수는 새로 여는 터미널부터 적용됩니다. 등록 전에 열려 있던 터미널이면 새 창에서 실행하세요.
$ claude
> /status
Anthropic base URL: https://alrouter.ai
4

테스트

간단한 프롬프트를 입력해 정상적으로 연결됐는지 확인합니다.

$ claude
> 연동 테스트입니다. "Claude Code 연결 성공"이라고만 답해주세요.
Claude Code 연결 성공
5

사용량 확인

모든 요청은 '사용 로그' 메뉴에서 키별로 토큰과 비용까지 확인할 수 있습니다. '개요' 화면에서도 최근 사용량을 요약해서 볼 수 있습니다.
