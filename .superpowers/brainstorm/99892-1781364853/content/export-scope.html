Export 범위 — 어떤 필드를 포함할까요?

민감한 데이터(비밀번호, 토큰)는 항상 제외됩니다. 그 외 범위를 선택해주세요.

A

기본 정보만

ID, Username, DisplayName, Email, Role, Status, Group, Quota, CreatedAt, LastLoginAt

가장 안전하고 단순. import 시 새 계정 생성/업데이트에 충분한 정보.

B

전체 관리 정보

기본 정보 + Remark, AffCode, AffQuota, InviterId, OrganizationId, OrganizationRole, UsedQuota, RequestCount

백업/마이그레이션 목적에 적합. 더 많은 데이터를 보존.

C

사용자 지정 (선택 가능)

Export 시 포함할 컬럼을 체크박스로 선택

유연하지만 UI가 복잡해짐. 필요한 경우에만 권장.
