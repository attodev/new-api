저장/취소 패턴의 적용 범위

어떤 변경 사항까지 "저장" 버튼을 눌러야 반영되게 할까요?

A

개별 행 편집만

quota 수정, 상태 토글 → 저장 전까지 pending 상태로 표시, 저장 버튼 클릭 시 일괄 반영

조직 제거·다중 비활성화 등 일괄 작업은 즉시 반영 (확인 다이얼로그 사용)

B

모든 변경 사항 통합

quota 수정, 상태 토글, 조직 제거, 다중 비활성화 전부 → 저장 버튼 클릭 시 일괄 반영

취소 버튼으로 모든 변경 내용 원복 가능

C

행 단위 인라인 저장

각 행에 편집 모드(연필 아이콘) → 행별로 저장/취소 버튼 표시

일괄 작업(다중 선택)은 별도 툴바에서 즉시 반영 (확인 다이얼로그)
