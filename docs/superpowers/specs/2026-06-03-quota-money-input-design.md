# Quota 금액 입력 개선 설계

## 목표

관리자와 조직 관리자가 quota를 내부 단위가 아니라 실제 금액처럼 이해하고 입력할 수 있게 한다. 현재 내부 기준은 `500,000 quota = $1`이며, 이 환산은 기존 프론트엔드의 quota 포맷/파싱 유틸리티를 그대로 사용한다.

## 범위

- 조직 사용자 관리 화면에서 raw quota 숫자 입력을 금액 기준 입력으로 바꾼다.
- 기존 관리자 사용자 quota 조정 다이얼로그에 빠른 금액 버튼을 추가한다.
- 백엔드 API와 DB 구조는 변경하지 않는다. 저장 직전에 프론트엔드에서 금액을 내부 quota 단위로 변환한다.
- 화면 문구는 i18n 키로 추가하고, 한국어 번역을 포함한다.

## 사용자 경험

조직 사용자 목록의 quota 칸은 현재 잔액을 `formatQuota` 결과로 보여준다. 사용자는 금액 입력칸에 `1`, `5`, `10` 같은 값을 넣어 목표 잔액을 지정할 수 있다. 빠른 버튼을 누르면 `$1`, `$5`, `$10`, `$100`에 해당하는 값이 바로 저장된다.

기존 관리자 quota 조정 다이얼로그는 더하기, 빼기, 덮어쓰기 모드를 유지한다. 여기에 빠른 버튼을 추가하여 큰 값을 직접 여러 번 증감하지 않아도 된다.

## 데이터 흐름

표시는 `formatQuota(quota)`를 사용한다. 입력값은 `parseQuotaFromDollars(amount)`로 내부 quota 단위로 변환한다. 기존 조직 사용자 수정 API는 absolute quota 값을 받으므로 조직 화면에서는 목표 잔액을 저장한다. 기존 관리자 quota 조정 API는 add/subtract/override 모드를 받으므로 다이얼로그에서는 기존 로직을 유지하고 입력 보조만 추가한다.

## 예외 처리

숫자가 아니거나 비어 있는 입력은 저장하지 않는다. 조직 사용자 화면에서 저장 실패 시 기존 toast 에러 처리를 그대로 사용한다. 토큰 전용 표시 모드에서는 빠른 버튼을 숨기고 입력 단위를 토큰으로 유지한다.

## 테스트

프론트엔드 빌드로 타입 오류를 확인한다. 브라우저에서는 조직 사용자 관리 화면에서 quota가 금액으로 표시되는지, `$1`, `$5`, `$10`, `$100` 버튼이 즉시 저장되는지, 관리자 사용자 quota 다이얼로그에서 빠른 금액 버튼이 입력값을 채우고 미리보기가 갱신되는지 확인한다.
