# 조직 대시보드 차트 확장 설계

## 목표

조직 소유자와 조직 관리자가 조직 내 사용량을 더 쉽게 파악할 수 있도록, 조직 대시보드의 그래프 영역을 관리자 대시보드의 차트 패턴에 가깝게 확장한다.

## 선택한 방향

사용자가 선택한 방향은 **B. 조직용 관리자 차트 세트**이다.

- 기존 요약 카드와 Top 사용자/모델 표는 유지한다.
- 현재 단순 추세 그래프는 관리자 대시보드에서 쓰는 `VChart` 기반 차트로 교체한다.
- 조직 사용량 분포는 `막대 / 영역` 전환을 제공한다.
- 조직 모델 분석은 `추세 / 비율 / Top` 탭을 제공한다.

## 데이터 설계

기존 조직 대시보드 응답에는 날짜별 조직 총 사용량과 모델별 총합만 있다. 모델별 추세 차트를 정확하게 만들기 위해 백엔드 응답에 모델별 일자 집계를 추가한다.

- `daily_usage`: 날짜별 조직 전체 사용량
- `top_models`: 기간 내 모델별 총합
- `model_usage`: 날짜와 모델을 함께 가진 사용량 집계

`model_usage`는 관리자 대시보드의 차트 유틸에서 사용하는 `QuotaDataItem` 형태로 변환할 수 있도록 `created_at`, `model_name`, `quota`, `count`에 대응되는 값을 프론트에서 만든다.

## 화면 설계

조직 대시보드는 다음 순서로 구성한다.

1. 조직 잔액, 조직 사용량, 기간 사용량, 기간 요청 수 요약 카드
2. 조직 사용량 분포 차트
3. 조직 모델 분석 차트
4. Top 사용자 표와 Top 모델 표

차트는 기존 관리자 대시보드와 같은 탭형 컨트롤과 테마 반영 방식을 사용한다.

## 검증

- 백엔드 조직 대시보드 모델 테스트에 `model_usage` 집계 검증을 추가한다.
- 프론트 빌드로 타입과 번들 생성을 확인한다.
- `git diff --check`로 공백 오류를 확인한다.
