# 조직 관리 기능 사용자 매뉴얼

## 1. 개요

이 매뉴얼은 조직 생성, 조직 사용자 관리, 조직 quota 지갑, 조직 사용량 모니터링, 조직 전용 구독 플랜을 UI에서 사용하는 방법을 설명한다.

조직 기능은 기존 사용자 `group`과 별개로 동작한다. `group`은 모델 접근과 과금 그룹 용도로 유지되며, 조직 소속은 별도 조직 필드로 관리된다.

## 2. 역할별 가능 작업

### 전체 관리자

전체 관리자는 모든 조직을 운영 관점에서 관리할 수 있다.

- 조직 생성
- 조직 소유자 지정
- 조직 quota 조정
- 조직 대시보드 조회
- 조직 사용 로그 조회
- 조직 작업 로그 조회
- 조직 구독 플랜 조회 및 관리
- 조직 선택 후 조직 소유자와 같은 관리 화면 확인

### 조직 소유자

조직 소유자는 자기 조직의 운영 책임자다.

- 조직 사용자 추가
- 조직 사용자 역할 관리
- 조직 사용자 quota 조정
- 조직 지갑 충전
- 조직 대시보드 조회
- 조직 사용 로그 조회
- 조직 작업 로그 조회
- 조직 구독 플랜 생성, 수정, 비활성화
- 조직 사용자에게 구독 플랜 할당, 변경, 취소

### 조직 관리자

조직 관리자는 자기 조직의 사용자 사용량과 구독을 관리한다.

- 조직 사용자 목록 조회
- 조직 사용자 상태 관리
- 조직 사용자 quota 조정
- 조직 대시보드 조회
- 조직 사용 로그 조회
- 조직 작업 로그 조회
- 조직 구독 플랜 생성, 수정, 비활성화
- 조직 사용자에게 구독 플랜 할당, 변경, 취소

### 조직 일반 사용자

조직 일반 사용자는 관리 기능을 사용할 수 없다.

- 자기 지갑 화면에서 조직이 할당한 quota 또는 조직 플랜 상태 확인
- API 요청 사용
- 자기 사용량과 요청 수 확인

## 3. 기본 개념

### 조직 quota

조직 quota는 조직 전체가 사용하는 선불 지갑이다. 조직 사용자가 API를 사용하면 최종 비용은 조직 quota에서 차감된다.

조직 quota가 부족하면 조직 구성원의 개인 quota 또는 구독 한도가 남아 있어도 요청은 실패한다.

### 사용자 quota

사용자 quota는 조직 내부에서 사용자별 사용 한도로 쓰인다.

조직 구독 플랜이 없는 사용자는 사용자 quota와 조직 quota가 모두 충분해야 요청할 수 있다.

### 조직 구독 플랜

조직 구독 플랜은 조직 내부 사용자에게 할당하는 별도 사용 한도다. 사용자가 직접 구매하거나 변경할 수 없다.

조직 구독 플랜을 받은 사용자는 개인 quota 대신 구독 플랜 한도를 사용한다. 이때도 최종 비용은 조직 quota에서 함께 차감된다.

### 조직 구독 자동 갱신

조직 구독은 플랜 기간이 끝나면 자동 갱신된다. `active` 상태의 구독은 만료 시간이 지나도 다음 사용 시 갱신 대상이 될 수 있다.

구독을 삭제하거나 취소하면 해당 사용자의 active 구독이 모두 취소되고 더 이상 자동 갱신되지 않는다.

## 4. 전체 관리자로 조직 생성하기

1. 전체 관리자 계정으로 로그인한다.
2. 사이드바에서 `조직 사용자` 메뉴로 이동한다.
3. `조직 생성` 영역에서 조직 이름을 입력한다.
4. 필요한 경우 설명을 입력한다.
5. 초기 조직 quota를 입력한다.
6. 소유자 사용자를 선택한다.
7. `생성` 버튼을 누른다.

주의할 점:

- 조직 소유자 선택 목록에는 조직에 속하지 않은 일반 사용자만 표시된다.
- 이미 다른 조직에 속한 사용자는 새 조직 소유자로 선택할 수 없다.
- 전역 관리자 또는 수퍼 관리자는 조직 소유자 후보에서 제외된다.
- 조직 이름은 64자 이하로 입력해야 한다.
- 설명은 255자 이하로 입력해야 한다.
- 초기 조직 quota는 0 이상 1,000,000,000 이하만 저장할 수 있다.

## 5. 전체 관리자로 조직 quota 조정하기

1. 전체 관리자 계정으로 로그인한다.
2. `조직 사용자` 메뉴로 이동한다.
3. `조직 quota 관리` 영역에서 대상 조직을 찾는다.
4. quota 입력칸에 새 금액을 입력한다.
5. `저장` 버튼을 누른다.

입력값은 화면의 currency/quota 표시 설정에 따라 금액 또는 token 기준으로 변환된다. 일반적인 금액 표시 모드에서는 `1`을 입력하면 `$1`에 해당하는 quota로 저장된다.

조직 quota는 서버에서 0 이상 1,000,000,000 이하로 제한한다. 화면에서 금액 단위로 보이더라도 저장 전 quota 단위로 변환된 값이 이 범위를 넘어가면 저장되지 않는다.

## 6. 조직 소유자로 사용자 추가하기

1. 조직 소유자 계정으로 로그인한다.
2. `조직 사용자` 메뉴로 이동한다.
3. `조직 멤버 할당` 영역에서 추가할 사용자를 선택한다.
4. 역할을 선택한다.
5. `할당` 버튼을 누른다.

선택 가능한 역할:

- `member`: 일반 사용자
- `admin`: 조직 관리자
- `owner`: 조직 소유자

## 7. 조직 사용자 quota 관리하기

1. 조직 소유자 또는 조직 관리자 계정으로 로그인한다.
2. `조직 사용자` 메뉴로 이동한다.
3. 사용자 목록에서 quota 영역을 확인한다.
4. quota 입력칸에 새 값을 입력한다.
5. Enter를 누르거나 입력칸 밖으로 이동해 저장한다.

빠른 버튼:

- `$1`
- `$5`
- `$10`
- `$100`

조직 구독 플랜이 할당된 사용자는 quota 입력칸이 비활성화된다. 이 경우 현재 quota는 `0 (조직 플랜 사용 중)`으로 표시된다.

서버 검증 기준:

- 사용자 quota: 0 이상 1,000,000,000 이하
- 사용자 상태: 활성 또는 비활성 값만 허용
- remark: 255자 이하

## 8. 조직 지갑 사용하기

### 조직 소유자

조직 소유자가 지갑 메뉴에 들어가면 개인 지갑 대신 조직 지갑을 중심으로 확인하고 충전할 수 있다.

확인 가능한 정보:

- 조직 quota
- 조직 사용량
- 충전 입력
- 결제 provider별 결제 버튼

### 조직 일반 사용자

조직 일반 사용자는 지갑에서 직접 충전할 수 없다.

조직 구독 플랜이 없는 경우:

- 현재 할당량
- 사용량
- 요청 수
- 조직에서 quota를 관리한다는 안내

조직 구독 플랜이 있는 경우:

- 현재 잔액 위치에 `조직 플랜 사용 중` 표시
- 사용량은 그대로 표시
- 요청 수는 그대로 표시
- 할당된 조직 플랜 이름, 사용량, 만료일 표시

## 9. 조직 구독 플랜 만들기

1. 조직 소유자 또는 조직 관리자 계정으로 로그인한다.
2. `조직 구독` 메뉴로 이동한다.
3. 플랜 제목을 입력한다.
4. 필요한 경우 부제목을 입력한다.
5. 금액 또는 quota 값을 입력한다.
6. 기간을 선택한다.
7. 기간이 `사용자 지정`이면 사용자 지정 초를 입력한다.
8. `생성` 버튼을 누른다.

플랜 입력 항목:

- 제목: 플랜 이름
- 부제목: 설명 또는 내부 메모
- 금액: 플랜 기간 동안 사용할 수 있는 한도
- 기간: 플랜 한도가 유지되는 기간
- 사용자 지정 초: 기간이 사용자 지정일 때만 입력 가능

현재 UI에서 제거된 항목:

- quota reset
- reset 사용자 지정 초
- upgrade group

quota reset은 별도로 설정하지 않고 플랜 기간과 동일하게 동작한다.

서버 검증 기준:

- 제목: 1자 이상 128자 이하
- 부제목: 255자 이하
- 금액 또는 quota: 0 이상 1,000,000,000 이하
- 기간: 연, 월, 일, 시간, 사용자 지정 중 하나
- 기간 값: 0 이상 1200 이하. 사용자 지정이 아니고 0이면 1로 저장된다.
- 사용자 지정 초: 사용자 지정 기간일 때 1 이상 31,536,000 이하

## 10. 조직 구독 플랜 수정 또는 비활성화하기

1. `조직 구독` 메뉴로 이동한다.
2. 조직 플랜 목록에서 수정할 플랜을 찾는다.
3. 수정 버튼을 눌러 폼에 값을 불러온다.
4. 값을 변경한 뒤 저장한다.

플랜을 더 이상 새 사용자에게 할당하지 않으려면 비활성화한다.

주의할 점:

- 비활성화된 플랜은 새 할당 대상에서 제외된다.
- 이미 사용자에게 할당된 구독은 별도 취소 전까지 사용자 구독 목록에 남을 수 있다.

## 11. 사용자에게 조직 구독 플랜 할당하기

1. `조직 구독` 메뉴로 이동한다.
2. `사용자 플랜 할당` 영역에서 사용자를 선택한다.
3. 할당할 플랜을 선택한다.
4. `할당` 버튼을 누른다.

동작 정책:

- 이미 active 플랜이 있는 사용자는 사용자 선택 목록에 표시되지 않는다.
- 같은 사용자에게 여러 active 플랜을 동시에 둘 수 없다.
- 새 플랜을 할당하면 기존 active 플랜은 먼저 취소되고 새 플랜이 생성된다.
- 할당 성공 후 선택한 사용자와 플랜 값은 초기화된다.

## 12. 사용자 조직 구독 취소하기

1. `조직 구독` 메뉴로 이동한다.
2. 현재 할당된 사용자 목록에서 대상 사용자를 찾는다.
3. 취소 또는 삭제 버튼을 누른다.

취소 후 동작:

- 해당 사용자의 active 조직 구독이 모두 취소된다.
- 취소된 구독은 기본 목록에서 숨겨진다.
- 사용자는 다시 일반 quota 방식으로 운영할 수 있다.
- 사용자를 다시 플랜 할당 드롭다운에서 선택할 수 있다.

## 13. 조직 대시보드 확인하기

1. 조직 소유자 또는 조직 관리자 계정으로 로그인한다.
2. `조직 대시보드` 메뉴로 이동한다.
3. 기간을 선택한다.

기간 옵션:

- 오늘
- 최근 7일
- 최근 30일
- 사용자 지정

확인 가능한 정보:

- 조직 quota
- 조직 사용량
- 기간 내 사용량
- 기간 내 요청 수
- 날짜별 사용량 추이
- 사용자별 사용량
- 모델별 사용량
- Top 사용자
- Top 모델

전체 관리자는 조직 선택 드롭다운에서 조직을 선택한 뒤 같은 화면을 확인한다.

## 14. 조직 사용 로그 확인하기

1. 조직 소유자 또는 조직 관리자 계정으로 로그인한다.
2. `조직 사용 로그` 메뉴로 이동한다.
3. 필요한 필터를 적용한다.
4. 로그 상세를 열어 요청 정보를 확인한다.

조직 구독으로 사용한 요청은 로그 상세에 조직 구독 정보가 표시될 수 있다.

예시 정보:

- 조직 구독 ID
- 조직 구독 플랜 ID
- 조직 구독 플랜 이름
- 구독 전체 한도
- 선차감 후 사용량

전체 관리자는 조직 선택 드롭다운에서 조직을 선택해 해당 조직의 사용 로그를 본다.

## 15. 조직 작업 로그 확인하기

1. 조직 소유자 또는 조직 관리자 계정으로 로그인한다.
2. `조직 작업 로그` 메뉴로 이동한다.
3. 조직 내부 사용자 작업 기록을 확인한다.

전체 관리자는 조직 선택 후 해당 조직의 작업 로그를 확인할 수 있다.

## 16. 전체 관리자의 조직 선택 유지

전체 관리자가 조직 대시보드, 조직 사용 로그, 조직 작업 로그, 조직 구독 화면에서 조직을 선택하면 마지막 선택 조직이 브라우저에 저장된다.

따라서 다른 메뉴로 이동했다가 돌아와도 마지막으로 보던 조직이 다시 선택된다.

## 17. 권장 테스트 순서

### 17.1 기본 조직 quota 방식

1. 전체 관리자로 조직을 생성한다.
2. 조직 소유자를 지정한다.
3. 전체 관리자로 조직 quota를 충분히 설정한다.
4. 조직 소유자로 로그인한다.
5. 조직 일반 사용자를 추가한다.
6. 조직 일반 사용자 quota를 설정한다.
7. 조직 일반 사용자로 API 요청을 실행한다.
8. 지갑에서 사용량과 요청 수가 증가하는지 확인한다.
9. 조직 대시보드에서 조직 사용량이 증가하는지 확인한다.
10. 조직 사용 로그에서 해당 요청이 보이는지 확인한다.

### 17.2 조직 구독 방식

1. 조직 소유자 또는 조직 관리자로 로그인한다.
2. 조직 구독 메뉴에서 플랜을 만든다.
3. 조직 사용자에게 플랜을 할당한다.
4. 해당 사용자로 로그인한다.
5. 지갑에서 `조직 플랜 사용 중`이 표시되는지 확인한다.
6. API 요청을 실행한다.
7. 조직 구독의 사용량이 증가하는지 확인한다.
8. 조직 대시보드에서 사용자/모델별 사용량이 표시되는지 확인한다.
9. 플랜 한도를 초과하는 요청이 실패하는지 확인한다.
10. 조직 구독을 취소하고 사용자가 다시 일반 quota 방식으로 돌아가는지 확인한다.

### 17.3 전체 관리자 모니터링

1. 전체 관리자로 로그인한다.
2. 조직 대시보드 메뉴로 이동한다.
3. 조직을 선택한다.
4. 조직 사용 로그와 조직 작업 로그로 이동한다.
5. 선택한 조직이 유지되는지 확인한다.
6. 다른 조직을 선택해 데이터가 바뀌는지 확인한다.

## 18. 자주 발생하는 오류와 대응

### 조직 quota 부족

증상:

- 요청 시 조직 quota 부족 오류가 발생한다.

대응:

- 전체 관리자 또는 조직 소유자가 조직 지갑을 충전한다.
- 전체 관리자는 조직 quota 관리 영역에서 quota를 조정할 수 있다.

### 사용자 quota 부족

증상:

- 조직 구독이 없는 사용자가 요청할 때 사용자 quota 부족 오류가 발생한다.

대응:

- 조직 소유자 또는 조직 관리자가 조직 사용자 화면에서 사용자 quota를 늘린다.

### 조직 구독 한도 부족

증상:

- 조직 구독 플랜 사용자에게 조직 구독 한도 부족 오류가 발생한다.

대응:

- 더 큰 플랜을 할당한다.
- 기존 플랜을 취소하고 일반 quota 방식으로 운영한다.
- 플랜 기간이 지나 자동 갱신되는지 확인한다.

### 플랜 삭제 후에도 사용자가 남아 보임

확인 사항:

- 취소된 구독은 기본 할당 목록에서 숨겨진다.
- 브라우저를 새로고침하거나 목록을 다시 조회한다.
- active 구독이 남아 있으면 취소 버튼을 다시 누른다.

### 지갑에 개인 잔액이 보이지 않음

조직 구독 플랜이 할당된 사용자는 정상 동작이다. 개인 잔액 대신 `조직 플랜 사용 중`이 표시된다.

### `default`가 표시됨

한국어 UI에서는 `default` 그룹 badge가 `기본값`으로 표시되어야 한다. 여전히 `default`가 보이면 브라우저를 새로고침한다.

## 19. 운영 팁

- 조직 quota는 조직 전체 예산이다. 사용자별 quota나 구독 한도보다 먼저 충분히 확보해야 한다.
- 조직 구독은 사용자별 한도를 명확히 관리하고 싶을 때 사용한다.
- 일회성 또는 단순 제한은 사용자 quota 방식이 더 간단하다.
- 조직 구독 플랜 사용자는 개인 지갑 충전 흐름을 사용하지 않는다.
- 조직 사용량 문제를 확인할 때는 조직 대시보드, 조직 사용 로그, 지갑 화면을 함께 확인한다.
